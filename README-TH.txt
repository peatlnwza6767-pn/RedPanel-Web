RED PANEL Web App

ติดตั้งบน iPhone:
1. อัปโหลด index.html ไปยัง repository GitHub ที่จะใช้เผยแพร่เว็บ
2. ใน GitHub เปิด Settings > Pages
3. เลือก Deploy from a branch, เลือก main และ /(root), แล้ว Save
4. รอจน GitHub Pages แสดงลิงก์เว็บไซต์
5. เปิดลิงก์นั้นใน Safari บน iPhone
6. กด Share > Add to Home Screen > Add

หมายเหตุ: เว็บนี้เป็น UI demo เท่านั้น ปุ่มและการตั้งค่าเปลี่ยนสถานะเฉพาะในหน้าเว็บ ไม่ได้ควบคุมระบบ iOS หรือแอปอื่น
GitHub Pages บัญชี Free ต้องใช้ repository สาธารณะสำหรับการเผยแพร่เว็บ อย่าใส่ข้อมูลส่วนตัวหรือ secret ลง repository
